# AI Resume Analyzer

A beginner-friendly Python project that analyzes a user's skills
and provides simple suggestions for AI/ML career preparation.

## Features

- Takes user's name as input
- Takes technical skills as input
- Detects Python skill
- Provides a basic career suggestion
- Built using Python

## Technologies Used

- Python
- VS Code
- Git & GitHub

## How to Run

1. Install Python
2. Clone this repository
3. Open the project folder
4. Run:

```bash
python app.py
